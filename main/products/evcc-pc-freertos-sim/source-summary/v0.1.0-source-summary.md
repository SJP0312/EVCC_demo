# v0.1.0 Source Summary

## Entry Layer

- `src/main.c`: top-level EVCC startup sequence. Calls `EVCC_Init`, creates configured OS tasks, and starts the scheduler.
- `include/main.h`: declares top-level EVCC lifecycle functions.

## L0_BSW_Layer

- `Lib_1`: exposes `Lib1_Init`, `Lib1_MainFunction`, and `I am Lib_1`.
- `Lib_2`: exposes `Lib2_Init`, `Lib2_MainFunction`, and `I am Lib_2`.
- `Lib_3`: exposes `Lib3_Init`, `Lib3_MainFunction`, and `I am Lib_3`.

## L1_RTE_Layer

- `Interface`: isolates L2 Apps from direct L0 access through independent per-App RTE files:
  - `Rte_App_1`: routes only `App_1` to `Lib_1`.
  - `Rte_App_2`: routes only `App_2` to `Lib_2`.
  - `Rte_App_3`: routes only `App_3` to `Lib_3`.
- `OS`: implements a pthread-backed FreeRTOS-style abstraction:
  - task config structure
  - task creation
  - scheduler start
  - delay
  - RUN/STOP global state
  - terminal command task

## L2_APP_Layer

- `App_1`: init/main/state-machine/public/private framework; 1s task, 5s heartbeat through `Rte_App1_GetLibInfo`.
- `App_2`: init/main/state-machine/public/private framework; 1s task, 10s heartbeat through `Rte_App2_GetLibInfo`.
- `App_3`: init/main/state-machine/public/private framework; 1s task, 15s heartbeat through `Rte_App3_GetLibInfo`.

## Build

- `Makefile`: compiles `src` and all L0/L1/L2 source folders, keeps generated object files under matching `build/...` module paths, adds include paths, and supports `THREAD_LINK=dynamic|static` for MinGW-w64 pthread linking. Dynamic pthread is the runnable default on this PC; static `winpthread` is selectable for machines whose Device Guard policy allows it.
- `.vscode/c_cpp_properties.json`: includes all module header folders for IntelliSense and navigation.

## Test

- `tests/run_layer_decoupling_check.ps1`: verifies App/RTE/Lib interface separation and blocks generic shared RTE APIs from returning.
- `tests/run_evcc_os_smoke.ps1`: builds the project, runs the executable, sends `1`, verifies heartbeats, sends `0`, and verifies no heartbeat appears after STOP.
