# v0.2.0 Source Summary

## Public API

- `L1_RTE_Layer/OS/include/Evcc_Os.h`
  - Added OS status codes: `EVCC_OS_OK`, `EVCC_OS_ERROR`, `EVCC_OS_TIMEOUT`.
  - Added wait constants: `EVCC_OS_NO_WAIT`, `EVCC_OS_WAIT_FOREVER`.
  - Added opaque handles for Queue, Semaphore, and EventGroup.
  - Added simulated interrupt handler type.
  - Added Queue, Semaphore, EventGroup, and Interrupt APIs.

## OS Internal Implementation

- `L1_RTE_Layer/OS/source/Evcc_Os_Internal.h`
  - Internal initialization hooks for OS resource pools.
- `L1_RTE_Layer/OS/source/Evcc_Os.c`
  - Calls resource-pool initialization from `EvccOs_Init`.
  - Existing task/scheduler behavior remains unchanged.
- `L1_RTE_Layer/OS/source/Evcc_Os_Queue.c`
  - Static ring-buffer queue pool.
  - Send/receive with no-wait, timed wait, and forever wait behavior.
- `L1_RTE_Layer/OS/source/Evcc_Os_Semaphore.c`
  - Static binary/counting semaphore pool.
  - Take/give with overflow and timeout behavior.
- `L1_RTE_Layer/OS/source/Evcc_Os_EventGroup.c`
  - Static event-group pool using `uint32`-style bit semantics through `EvccOs_EventBitsType`.
  - Set, clear, wait-any/wait-all, and clear-on-exit behavior.
- `L1_RTE_Layer/OS/source/Evcc_Os_Interrupt.c`
  - Static interrupt table.
  - Register, enable, disable, and trigger APIs.
  - Handlers are called outside the interrupt table mutex to avoid deadlock.

## Tests

- `tests/os_api_test.c`
  - Compiles against the OS abstraction API.
  - Verifies Queue, Semaphore, EventGroup, and Interrupt behavior.
- `tests/run_evcc_os_api_check.ps1`
  - Builds and runs the OS API test without linking APP/RTE/BSW layers.

## Notes

- Priority remains a task configuration field. The pthread backend does not implement hard real-time FreeRTOS preemption.
- The unused `Lib_2` static heartbeat variable was removed to keep full-project verification warning-free.
