# v0.4.0 Source Summary

## Imported Stack

The repository now contains the EVCC BSW modules for CryIf, Crypto_30_LibCv,
Csm, Ethernet/Ethernet transceiver interfaces, EthSM, EXI, IpBase, KeyM, Scc,
Slac, TcpIp, VStdLib, XmlSecurity, and vSecPrim, together with generated RTE
configuration under `L1_RTE_Layer/Interface/GenData`.

## Build Integration

- `Makefile`
  - Recursively discovers C/C++ sources and header directories.
  - Compiles the imported protocol stack and generated interface configuration.
  - Excludes target application random/time sources replaced by host adapters.
  - Defines `MICROSAR_DISABLE_MEMMAP` by default.
  - Supports `DISABLE_AUTOSAR_MEMMAP=0` for a future target toolchain.
  - Keeps dependency-file generation and fixes parallel `rebuild` ordering.

- `.vscode/c_cpp_properties.json`
  - Adds recursive BSW and generated-interface include paths.
  - Defines `MICROSAR_DISABLE_MEMMAP` for IntelliSense.

## PC Compatibility Layer

`L0_BSW_Layer/_Common/Autosar_Common` supplies the missing host-side interfaces:

- AUTOSAR Det, NvM, ComM, RTE type, and communication callback definitions.
- SchM module headers backed by a common no-op host implementation.
- SPI, Ethernet callback, random, time, certificate, and application stubs.
- Scc callback and Csm notification signature adaptation.
- A no-op MemMap adapter for host simulation.

The common `MemMap.h` selects the no-op adapter when
`MICROSAR_DISABLE_MEMMAP` is defined. Generated module MemMap headers use the
same switch, so target section/MPU directives are not processed on Windows.

## Type and Include Compatibility

- `PduLengthType` is provided as `uint16` through `Std_Types.h`.
- `NvM_RequestResultType` is provided as `uint8` through `NvM.h`.
- `EcuM_WakeupSourceType` is provided as `uint8` in `EthIf_GenTypes.h`.
- Requested Scc application includes use `_ApplScc_CbkStubs.h`.
- Include-name case and underscore mismatches were aligned with real filenames.

## Scope Notes

No cryptographic, EXI, SCC state-machine, TCP/IP, or Ethernet algorithm was
rewritten. Compatibility changes are limited to build discovery, generated
include bindings, base types, and PC-side adapters.
