## Acceptance Checklist

- `src` remains the top-level entry source directory.
- L0/L1/L2 modules are separated.
- Each App has its own RTE header/source interface.
- Each App only calls its matching RTE API.
- Each Lib has its own init, main, and get-info API.
- App code does not include BSW Lib headers directly.
- Generic shared RTE APIs are not used.
- App1 prints every 5s from a 1s task.
- App2 prints every 10s from a 1s task.
- App3 prints every 15s from a 1s task.
- App1 heartbeat uses `I am Lib_1`.
- App2 heartbeat uses `I am Lib_2`.
- App3 heartbeat uses `I am Lib_3`.
- Input `1` starts task execution.
- Input `0` pauses task execution.
- STOP suppresses additional heartbeats.
- Default build uses dynamic pthread linking and runs on this PC.
- Static `winpthread` mode is available with `THREAD_LINK=static`, but this PC's Device Guard policy blocks the resulting executable.
