# v0.2.0 Design

## Goal

Extend the existing pthread-backed EVCC PC OS abstraction with stable FreeRTOS-style synchronization primitives while keeping APP, RTE, and BSW business layers independent of pthread and Windows APIs.

## Scope

This iteration adds OS-layer APIs for queues, semaphores, event groups, and simulated interrupts. The implementation uses fixed static resource pools, pthread mutexes, and pthread condition variables. Dynamic memory allocation is intentionally avoided.

## Architecture

- `Evcc_Os.h` exposes the public OS abstraction API.
- `Evcc_Os.c` keeps task creation, scheduler, delay, RUN/STOP state, and synchronized printing.
- `Evcc_Os_Queue.c` provides ring-buffer queues.
- `Evcc_Os_Semaphore.c` provides binary and counting semaphores.
- `Evcc_Os_EventGroup.c` provides bit-based event synchronization.
- `Evcc_Os_Interrupt.c` provides PC-side simulated interrupt registration and triggering.
- `Evcc_Os_Cfg.c` remains the engineering binding layer for ASW task headers and task configuration.

## Migration Intent

The API names and behavior are shaped so a later FreeRTOS port can map them to `xQueue*`, `xSemaphore*`, `xEventGroup*`, `xTaskCreate`, and `vTaskDelay` style primitives inside `Evcc_Os.c`/OS source files without forcing APP/RTE/BSW layers to include FreeRTOS headers directly.

## Out Of Scope

- Real MCU ISR execution.
- FreeRTOS-style hard real-time priority preemption.
- Windows real-time thread priority changes.
- Heap allocator and object delete APIs.

## Acceptance Criteria

- Queue send/receive works with copied payloads and no-wait timeout behavior.
- Binary/counting semaphores support take/give and overflow protection.
- Event groups support set, wait-all, clear-on-exit, and no-wait timeout behavior.
- Simulated interrupts support register, enable, trigger, disable, and lightweight FromISR-style API usage.
- Existing App1/App2/App3 heartbeat behavior remains unchanged.
- OS implementation files do not include or reference APP/RTE/BSW identifiers except the intentional `Evcc_Os_Cfg.c` task binding file.
