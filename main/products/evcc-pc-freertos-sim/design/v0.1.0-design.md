# v0.1.0 Design

The implementation keeps `src` as the top-level entry source directory, separates simulated BSW libraries under `L0_BSW_Layer`, exposes data through `L1_RTE_Layer/Interface`, and implements a pthread-backed FreeRTOS-style OS abstraction under `L1_RTE_Layer/OS`.

The simulator creates task threads once and uses terminal commands to control global execution state:

- `1`: RUN, task main functions execute on configured periods.
- `0`: STOP, task threads remain alive but skip business logic.

Acceptance requires App1 5s heartbeat with `I am Lib_1`, App2 10s heartbeat with `I am Lib_2`, and App3 15s heartbeat with `I am Lib_3`. This validates the RTE routing pairings `App_1 -> Lib_1`, `App_2 -> Lib_2`, and `App_3 -> Lib_3`.
