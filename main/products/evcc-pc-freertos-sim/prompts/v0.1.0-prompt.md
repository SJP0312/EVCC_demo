# v0.1.0 Engineering Prompt

Implement a PC-side FreeRTOS-style multitask simulation framework in `EVCC_demo`.

Use C17 and MinGW-w64 pthread/winpthreads. Keep `src` as the top-level entry source directory. Add separated L0/L1/L2 module folders with include/source subfolders. L0 contains Lib1/Lib2/Lib3 simulated configuration providers. L1 contains RTE interfaces and an OS abstraction with task creation, scheduler start, delay, global RUN/STOP state, and a console command task. L2 contains App1/App2/App3 components with init, main function, state machine, private, and public functions.

Implement App1 as a 1s task that prints every 5s with `I am Lib_1`. Implement App2 as a 1s task that prints every 10s with `I am Lib_2`. Implement App3 as a 1s task that prints every 15s with `I am Lib_3`. Input `1` starts or resumes task execution. Input `0` pauses task execution without terminating the process.

Update Makefile and VSCode C/C++ include paths. Keep the pthread OS backend and provide selectable dynamic/static `winpthread` linking. Use dynamic pthread as the runnable default on this PC because Device Guard blocks static `winpthread` executables. Add an automated smoke test for command input and heartbeat output. Archive verification results under `main/products/evcc-pc-freertos-sim`.
