# v0.2.0 Engineering Prompt

Implement stable FreeRTOS-style OS abstraction primitives in the EVCC PC simulation project.

Modify only the OS abstraction layer and verification/archive files unless a pre-existing warning prevents clean verification. Keep APP/RTE/BSW architecture unchanged.

Required OS APIs:

- Queue: create, send, receive, send-from-ISR.
- Semaphore: create binary, create counting, take, give, give-from-ISR.
- EventGroup: create, set bits, clear bits, wait bits.
- Interrupt simulation: register, enable, disable, trigger.

Implementation constraints:

- Use C17 and pthreads.
- Use fixed static resource pools.
- Avoid dynamic allocation.
- Use `pthread_mutex_t` and `pthread_cond_t`.
- Return stable status codes: OK, ERROR, TIMEOUT.
- Preserve existing scheduler and heartbeat behavior.
- Do not add APP/RTE/BSW includes to OS implementation files.
- Keep priority as a configuration field; do not implement Windows real-time priority.

Verification:

- Add an OS API unit-style test that compiles only OS sources and validates queue/semaphore/event-group/interrupt behavior.
- Run the existing layer decoupling check.
- Run the existing EVCC OS smoke test.
- Record results under `main/products/evcc-pc-freertos-sim`.
